# Echo Loop

**כל 10 שניות הזמן מתאפס. כל מה שעשית — חוזר להילחם לצידך.**

משחק ארקייד בדפדפן. אתה שורד לולאה של 10 שניות, הזמן נגלל אחורה, והריצה שלך הופכת ל**הד** — עותק שלך שחוזר על כל צעד וכל יריה. עד 12 הדים במקביל: אתה בונה צבא מעצמך. האויבים מגיעים באותם מקומות בכל לולאה, כך שמה שעשית בעבר באמת עוזר לך עכשיו, אבל כל לולאה מביאה יותר מהם, ו**הסגולים** צדים את ההדים שלך.

## איך משחקים
- **מקלדת:** WASD או חיצים לתזוזה, עכבר לכיוון, הירי אוטומטי. `P` עוצר, `M` משתיק.
- **מגע:** גוררים בכל מקום על המסך (ג'ויסטיק צף). הכיוון והירי אוטומטיים. בטלפון עומד הזירה מסתובבת כדי למלא את המסך.

## הרצה
אין התקנה ואין תלויות. אפשר פשוט לפתוח את `index.html` בדפדפן, או להריץ שרת סטטי:

```bash
cd echo-loop
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## בדיקות
צריך Node 18 ומעלה.

```bash
npm test                       # 12 בדיקות למנוע (דטרמיניזם, הקלטה, הדים, פגיעות, תקרות)
node tests/smoke.browser.js    # בדיקת עשן בדפדפן אמיתי (צריך Playwright): משחק לולאה מלאה ובודק שנוצר הד
```

## מבנה
```
index.html             מסכים ו-HUD
src/engine.js          לוגיקת משחק טהורה ודטרמיניסטית (בלי DOM), 60 טיקים בשנייה
src/main.js            קלט, לולאה בצעד קבוע, רינדור Canvas, סאונד WebAudio מסונתז
src/style.css          עיצוב
tests/engine.test.js   בדיקות יחידה למנוע (node:test)
tests/smoke.browser.js בדיקת עשן בדפדפן
COUNCIL.md             פאנל הבוטים, הטורניר והנימוקים
```

**ארכיטקטורה בקצרה:** המנוע מקבל קלט אחד בכל טיק ומקליט `{x, y, כיוון, ירה?}`. בסוף הלולאה ההקלטה הופכת להד, וההד פשוט קורא אותה טיק אחרי טיק. מכיוון שהצעד קבוע וההופעה של האויבים נגזרת מזרע קבוע, השחזור מדויק.

## פרטיות
אין שרת, אין רשת ואין עוגיות. הדבר היחיד שנשמר הוא השיא שלך, ב-`localStorage` של הדפדפן.
