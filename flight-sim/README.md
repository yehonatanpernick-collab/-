# רקיע — סימולטור טיסה תלת־ממדי

סימולטור טיסה בדפדפן (Three.js / WebGL), קובץ HTML אחד, בלי התקנה.

## מה יש בפנים
- **שלושה מטוסים** עם מודל טיסה פיזיקלי מלא (6 דרגות חופש):
  - **ARROWHEAD FX** — מטוס קרב: מבער אחורי, Fly-by-wire עם הגבלת 9G וזווית התקפה, קצב גלגול של כ־230°/ש', וו נחיתה, בלם אוויר.
  - **WREN L-2** — מטוס קל: הגאים ישירים (בלי מחשב), מדחף עם אפקט P-factor, טרים, צופר הזדקרות.
  - **MERIDIAN M-200** — מטוס נוסעים: חוק בקרה בסגנון Airbus (הגנות גובה/גלגול/זווית התקפה), דחף הפוך, ספוילרים אוטומטיים בנגיעה, טייס אוטומטי.
- **עולם פתוח של כ־60×60 ק"מ**: חוף, איים, הרים מושלגים, יערות, שדות חקלאיים, עיר עם אלפי בניינים ואורות לילה.
- **3 שדות תעופה** עם מסלולים מסומנים, אורות מסלול, תאורת גישה, PAPI אמיתי, מגדל פיקוח, האנגרים ומטוסים חונים, ו**נושאת מטוסים** עם קטפולטה וכבלי עצירה.
- **אטמוספירה**: שמיים פיזיקליים, 4 שעות ביום, עננים, ערפל, כוכבים, רוח צד ומערבולות.
- **HUD** קונפורמי (סולם עלרוד, וקטור מסלול טיסה, סרגלי מהירות וגובה, מחוון ILS), תא טייס עם לוח מכשירים חי, מפה.
- **אפקטים**: מבער אחורי, עשן צמיגים, שובלי אדים בעומס G, קונוס על־קולי, שובלי סילון בגובה, פיצוצים.
- **סאונד מסונתז**: מנועים, רוח, אזהרות GPWS וקריאות גובה בנחיתה.
- **ציון נחיתה**: קצב שקיעה, סטייה מקו האמצע, כבל על הנושאת.
- תמיכה במקלדת, בקר משחק ומסך מגע.

## תרחישים
המראה · גישה לנחיתה · שיגור מנושאת · נחיתה על נושאת · שדה הרים · מסלול טבעות · טיסה חופשית

## מקשים
| פעולה | מקש |
|---|---|
| גובה / גלגול | `W` `S` `A` `D` או חצים |
| הגה כיוון | `Q` `E` |
| מצערת | `Shift` / `Ctrl` (או `+` / `-`), `Home` מלאה, `End` סרק |
| גלגלים / מדפים | `G` / `F` `R` |
| בלמים / בלם חניה | `Space` / `P` |
| בלם אוויר, דחף הפוך, טרים | `X`, `N`, `[` `]` |
| טייס אוטומטי, וו נחיתה, קטפולטה | `Z`, `K`, `Enter` |
| מצלמות | `C` או `1`–`5` |
| HUD, מפה, קול, השהיה | `H`, `M`, `T`, `Esc` |

## הרצה ופיתוח
פתח את `index.html` בדפדפן (דרוש חיבור לאינטרנט לטעינת Three.js מ־CDN).

הקוד נמצא ב־`src/` (מחולק לקבצים לפי נושא). לבניית הקובץ המאוחד:
```
python3 build.py
```
