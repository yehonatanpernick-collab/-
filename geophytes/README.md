# 🌷 אתגר הגאופיטים של ישראל

אפליקציית שטח (PWA) למציאת **כל הגאופיטים של ישראל** במהלך השנה.
בוחרים אזור בארץ ← מקבלים את רשימת כל הגאופיטים שגדלים בו (מהנפוצים ועד שרידי אוכלוסיות זעירות) ← מצלמים ← **Claude** (בינה מלאכותית של Anthropic) בודק את הצילום ומאשר שזה באמת המין ← ✓ ברשימה.

## מה יש בפנים

- **303 טקסונים**: כל מה שמוגדר "גיאופיט" במאגר [צמחיית ישראל וסביבתה](https://flora.org.il/plants/life-form/geophyte/), כולל זנים (var.), הכלאות (×) וטקסונים שעוד לא תוארו (aff.).
- **27 אזורים** של המאגר (281 טקסונים משויכים לאזורים; 22 שבמקור אין להם תפוצה בישראל – עבר הירדן, מינים זרים, טקסונים חדשים – מרוכזים ברשימה נפרדת), מקובצים ל-**8 אזורי אקלים** (הררי-אלפיני, ים-תיכוני לח, מישור החוף, הרים וגבעות, עמקים חמים, ספר וערבות, מדברי, סודני).
- לכל מין: שכיחות בכל אזור (נפוץ / מצוי / נדיר / נדיר מאוד / נכחד), חודשי פריחה, מעמד (מוגן, אנדמי, בסכנת הכחדה, פולש), איבר אגירה, בית גידול, סימני זיהוי, מידע על הסוג (אקולוגיה, האבקה, תרבות, רעילות), וקישור לתמונות ב"צמחיית ישראל".
- **הסבר מורחב מ-AI** לכל מין: זיהוי, מינים דומים, מחזור חיים, אקולוגיה, האבקה, נדירות, שמירת טבע, תרבות ושימושים.
- **אימות תצפית מצילום**: עד 3 תמונות; Claude מקבל את המין המבוקש, את קרוביו בארץ ואת רשימת כל הגאופיטים, ומחזיר זיהוי, אחוז ביטחון, נימוק, אפשרויות חלופיות ומה לצלם כדי לשפר. ✓ ניתן רק כשהזיהוי ברמת מין ומעל סף הביטחון (ברירת מחדל 80%), ורק לצילום אמיתי בשטח (לא צילום מסך/הדפסה).
- **זיהוי חופשי**: "מה הצמח הזה?" – ואם הוא ברשימה, אפשר לסמן אותו.
- מעקב לפי שנה, סינון (חסרים / פורחים עכשיו / נדירים / מוגנים / אנדמיים / סוג צמח), גיבוי וייבוא, עבודה מהטלפון כאפליקציה מותקנת.

## הפעלה

```bash
node geophytes/server.js            # http://localhost:8090
```

ואז בהגדרות (⚙) מדביקים מפתח API מ-[console.anthropic.com](https://console.anthropic.com/settings/keys).
המפתח נשמר רק בדפדפן שלכם ונשלח רק ל-Anthropic.

כדי שהמפתח יישאר בשרת ולא בדפדפן (למשל כשמשתפים עם המשפחה):

```bash
ANTHROPIC_API_KEY=sk-ant-... node geophytes/server.js
```

ובהגדרות בוחרים "דרך השרת".

אפשר גם להגיש את התיקייה מכל שרת סטטי (GitHub Pages וכו') ולהשתמש במצב "מפתח אישי בדפדפן". לשימוש בטלפון בשטח: פותחים בדפדפן ← "הוסף למסך הבית".

## עדכון הנתונים

`data/raw/list.tsv` – רשימת המינים; `data/raw/*.json` – הנתונים שחולצו מעמודי המינים. לבנייה מחדש של `data/species.js`:

```bash
node geophytes/tools/build-data.mjs
```

## הערות

- המאגר מגדיר "גיאופיט" בהרחבה, כך שהרשימה כוללת גם דגנים בעלי קנה שורש, צמחי מים ומטפסים. אפשר לסנן ל"גאופיטים קלאסיים (בצל / פקעת)" בלבד.
- רוב הגאופיטים מוגנים בחוק: מצלמים, לא קוטפים ולא עוקרים.
