# עוזר הגיטרה 🎸

אפליקציית ווב ללא תלויות (HTML/CSS/JS). פותחים את `index.html` בדפדפן, או: `python3 -m http.server` ואז http://localhost:8000
(המיקרופון של המכוון דורש localhost או HTTPS).

- **מכוון**: זיהוי גובה צליל מהמיקרופון (אוטו-קורלציה), מחוון סנטים, צלילי ייחוס למיתרים
- **מטרונום**: תזמון מדויק עם Web Audio, טאפ טמפו, 2/3/4/6 פעימות
- **אקורדים**: דיאגרמות ל-25 אקורדים, והאקורדים של כל סולם מז׳ור
- **סולמות**: צוואר גיטרה מלא עם 7 סולמות
- **יומן תרגול**: סטופר ושמירת מפגשים ב-localStorage

בדיקות: `node test.js`
