# ממלכות אֶתֶרְיָה – Realms of Aetheria

משחק הרפתקאות פנטזיה בתלת־ממד שרץ בדפדפן, במחשב ובטלפון.

חמש ממלכות, וכל אחת מייצגת סוג אחר של פנטזיה:

| ממלכה | סוג הפנטזיה | מה יש בה |
|---|---|---|
| ☀ אחו השמש | Light Fantasy | אחו מוזהב, מזבח האתר, ליאורה הפיה |
| 🍄 היער המכושף | Fairytale Fantasy | פטריות זוהרות, בקתת אגדות, מגדל קסום, גובליני פטריות |
| ⚱ מקדש הטיטאנים | Mythic Fantasy | מקדש שיש, פסל טיטאן ענק, שומרי אבן |
| ⛰ פסגות הבדולח | Adventure Fantasy | הרים מושלגים, איים מרחפים, קשת בדולח, עכבישי בדולח |
| ☾ ממלכת הצללים | Dark Fantasy | ים לבה, טירה אפלה, רוחות צל, והבוס: **המלך החלול** |

## איך משחקים
- **מחשב:** WASD לתנועה, העכבר מזיז את המצלמה, קליק שמאלי לחרב (קליקים ברצף לקומבו של 3 מכות), קליק ימני או Q לכדור קסם, רווח לקפיצה, Shift להתחמקות, גלגלת לזום, Esc לתפריט.
- **טלפון:** ג׳ויסטיק בצד שמאל, גרירה בצד ימין לסיבוב המצלמה, וכפתורים לחרב, קסם, קפיצה והתחמקות. כדאי לסובב את הטלפון לרוחב.

**המטרה:** להביס את השומרים ולאסוף את שלושת רסיסי לב האתר. אז נפתח מחסום הצללים, ואפשר להילחם במלך החלול, לקחת ממנו את הרסיס האחרון ולהחזיר את כולם למזבח.

## הרצה
המשחק סטטי ואין בו שלב build. צריך רק להגיש את התיקייה משרת אינטרנט כלשהו (פתיחה ישירה כ־`file://` לא תעבוד בגלל ES modules):

```bash
cd realms
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

אפשר גם לפרסם ב־GitHub Pages ולגשת לכתובת `/realms/`.

## טכנולוגיה
- Three.js (r187) מוטמע מקומית בתיקייה `lib/`, כך שאין תלות ב־CDN.
- עולם פרוצדורלי: פני שטח מרעש simplex, מעברים חלקים בין ביומות, שמיים, ערפל ותאורה שמשתנים לפי הממלכה שבה נמצאים.
- מים ולבה מבוססי shader, דשא מונפש ברוח, אלפי עצמים עם instancing, צללים דינמיים ו־bloom.
- אנימציה פרוצדורלית לגיבור ולאויבים, שובל חרב, חלקיקים, hit-stop ורעידות מצלמה.
- מוזיקה ואפקטים קוליים שנוצרים בזמן אמת עם WebAudio, והמוזיקה מתחלפת לפי הממלכה.
- שלוש רמות איכות גרפיקה: גבוהה, בינונית ונמוכה. בטלפון ברירת המחדל היא בינונית.
