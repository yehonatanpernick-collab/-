# ממלכות אֶתֶרְיָה – Realms of Aetheria

משחק פעולה והרפתקאות בתלת־ממד שרץ בדפדפן (מחשב וטלפון). חמישה פרקים, כל אחד בסוג אחר של פנטזיה:

| פרק | ממלכה | סוג | מטרה | בוס |
|---|---|---|---|---|
| I | אחו השמש | Light | להביס שלדים ולהדליק 3 משואות | — |
| II | היער המכושף | Fairytale | לשחרר 4 פיות כלואות | מורגנה, המכשפה האפלה |
| III | מקדש הטיטאנים | Mythic | לשרוד 3 גלים של אויבים | אקמון, טיטאן השיש |
| IV | פסגות הבדולח | Adventure | לקפוץ בין איים מרחפים ולאסוף 5 בדולחים | — |
| V | ממלכת הצללים | Dark | לנפץ 3 אובליסקים | המלך החלול |

## הרצה
```bash
cd realms && python3 -m http.server 8000   # ואז לפתוח http://localhost:8000
```

## נכסים ורישיונות
- דמויות ואויבים: KayKit Adventurers / Skeletons / Halloween Bits (CC0, Kay Lousberg)
- עצים: EZ-Tree (MIT, Daniel Greenheck), כולל טקסטורות קליפה ועלים, סלעים ופרחים
- שמי HDR וטקסטורות מים ולבה: מתוך דוגמאות three.js (Poly Haven CC0)
- קבצים בינאריים (`.glb`, `.hdr`) נשמרים כ־base64 בתוך `*.json`, כי שרת האירוח מגיש רק קובצי טקסט ותמונות. המשחק מפענח אותם בחזרה לבייטים המקוריים.
