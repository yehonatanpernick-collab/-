# TrekAtlas · אטלס טרקים

אפליקציית ווב בעברית לחקירת הרים ונופי טבע בעולם על מפה תלת-ממדית, ולתכנון טיולים וטרקים: מרחק, עלייה וירידה, פרופיל גובה, זמן הליכה, חלוקה לימים ותחזית מזג אוויר לכל יום.

## הרצה

אין צורך בהתקנה, במפתחות API או בשרת אחורי. הפרויקט הוא דף סטטי:

```bash
cd trekatlas
python3 -m http.server 8000      # או כל שרת סטטי אחר
# פתחו http://localhost:8000
```

אפשר גם לפתוח את `index.html` ישירות בדפדפן. נדרש חיבור לאינטרנט בשביל המפות והנתונים.

## בדיקות

```bash
node --test trekatlas/test/*.test.js
```

הבדיקות מכסות את כל החישובים: מרחקים (haversine), דגימת מסלול, פענוח גובה מאריחי Terrarium, קצב הליכה לפי טובלר, עלייה מצטברת עם סינון רעש, חלוקה לימים, ייבוא וייצוא של GPX, ובריחת HTML.

## מה יש בפנים

| לשונית | מה עושים בה |
|---|---|
| 🌍 גלה | גלובוס תלת-ממדי מסתובב עם 62 יעדים מובחרים וחיפוש בכל העולם. לכל מקום יש כרטיס עם תמונה ותיאור מוויקיפדיה (בעברית כשיש), גובה, מזג אוויר עכשיו ומקומות בסביבה |
| 🥾 תכנן | לחיצות על המפה בונות מסלול שנצמד לשבילים ולדרכים. מקבלים רמת קושי, פרופיל גובה צבוע לפי שיפוע, זמן הליכה, חלוקה לימים, ולכל יום תחזית, זריחה ושקיעה ואזהרה אם היום ארוך מאור היום. יש גם טיסה תלת-ממדית מעל המסלול |
| 🎒 הטיולים שלי | טיולים שמורים בדפדפן, עם אפשרות לפתוח או למחוק |

עוד יכולות: ייצוא GPX לשעון או לאפליקציית ניווט, ייבוא GPX, שיתוף מסלול בקישור (הנקודות נשמרות ב-`#r=` שבכתובת), החלפה בין שכבת לוויין לשכבה טופוגרפית, ושבילים ופסגות מ-OpenStreetMap בזום 12 ומעלה.

## מקורות נתונים (כולם חינמיים, בלי מפתח)

- **גובה:** Mapzen Terrain Tiles ב-AWS · **מפה:** MapLibre GL 5.24 בתצוגת גלובוס (קידוד Terrarium, זום 12 ≈ 30 מ׳ לפיקסל)
- **לוויין:** Esri World Imagery · **טופוגרפית:** OpenTopoMap
- **שבילים לניתוב:** OSRM foot (routing.openstreetmap.de)
- **תמונות ותיאורים:** ויקיפדיה (עברית ואנגלית)
- **חיפוש:** Nominatim של OpenStreetMap (רק בלחיצה על "חפש", בהתאם למדיניות השימוש שלהם)
- **שבילים ופסגות:** Overpass API (OpenStreetMap)
- **מזג אוויר:** Open-Meteo, מותאם לגובה הנקודה

## מגבלות ידועות

- ההצמדה לשבילים משתמשת בשרת ההדגמה של OSRM ב-FOSSGIS (פרופיל הליכה). הוא מתאים לשימוש קל. כשהוא לא זמין, הקטעים מחושבים בקו ישר ומסומנים במקווקו.
- זמן ההליכה מחושב לפי נוסחת טובלר, בלי הפסקות. בשטח טכני, בשלג או בגובה רב הזמן בפועל ארוך יותר.
- תחזית מזג אוויר זמינה רק ל-16 הימים הקרובים.
- טיולים שמורים נשמרים בדפדפן הנוכחי בלבד. לגיבוי משתמשים בייצוא GPX.
- הקואורדינטות ברשימת היעדים משוערות, ומיועדות להטסת המפה ולא לניווט.
