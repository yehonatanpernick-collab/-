# עולמות פראיים — אנציקלופדיה מאוירת

- `wild-worlds-encyclopedia.pdf` — הספר המוגמר (A4 לאורך, RTL, 45 עמודים: כריכה, מבוא, תוכן עניינים, 40 עמודי תוכן, סיכום, מקורות).
- בנייה מחדש: `cd src && python3 genmaps.py && python3 genfigs.py && python3 build.py front p1a p1b p1c p2a p2b p3a p3b p4a p4b p5 back && node render.js`
- מפות: ETOPO1 (NOAA) ו-Blue Marble (NASA) דרך נתוני matplotlib basemap; איורים: SVG סכמטיים.
